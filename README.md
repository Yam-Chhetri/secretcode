# 🛰️ geomatics-crush-confession

> *"All coordinates lead straight to you. Why send a plain text when you can calibrate an entire geomatics web application?"* 📐🗺️✨

An interactive, romantic Geomatics Engineering-themed single-page web app built by **Yam Chhetri** (BGE student at IOE WRC Pokhara, Lamachaur) to ask someone special out on a date. Built with pure HTML5, CSS3, and Vanilla JavaScript — zero heavy dependencies, lightning-fast, and mobile-friendly.

---

## ✨ Features

- 🛰️ **Terminal Boot-Up Screen (`geomatics_survey_feelings.sh`)**: Realistic terminal typing animation calibrating Total Station at WRC Lamachaur, locking 18 GNSS satellites, and measuring horizontal angle to their heart.
- 🎨 **Aesthetic Geomatics Vibes**: Glowing dark theme with neon gradients, paired with `Plus Jakarta Sans`, `Fira Code`, and floating survey markers & hearts (`📍`, `🛰️`, `🧭`, `💖`).
- 📐 **Candidate Technical Specs**: Geomatics-style profile cards:
  - *Lakeside Topographic Chai & Coffee Pipeline* (0.00% closure error on snacks)
  - *Pokhara Scooter Traverse API* (100% smooth ride along Pame & Sarangkot)
  - *Drone Photogrammetry & Aesthetic Portraits* (Sub-centimeter resolution with Machhapuchhre backdrop)
  - *Date Itinerary GIS Engine* (Geodesic romantic routes in Pokhara)
- 📝 **Survey Field Notes / Changelog**: Release notes highlighting *Your Smile's Elevation*, *Magnetic Declination Anomaly*, and *Optimized Weekend Spatial Schedule*.
- 🏃‍♂️ **Runaway "NO" Button**: The "No" button dodges cursor/touches within the coordinate grid while cycling through witty surveying error messages and scaling up the "YES" button.
- 🎶 **Web Audio Synthesizer**: 8-bit retro sound effects generated on the fly via the Web Audio API.
- 🎟️ **Official Field Survey Pass & WhatsApp Integration**: Saying "YES" generates an official date pass with Pokhara rendezvous options and creates a pre-formatted message sent directly to Yam on WhatsApp (`+977 9764540987`).

## 🚀 Quick Start

### 1. View Locally
Simply double-click `index.html` to open it in any modern browser.

Or start a local preview server:
```bash
# Python 3
python -m http.server 8080
```
Visit `http://localhost:8080` in your browser.
